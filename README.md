# App Trend Analysis

An end-to-end data analyst project analyzing Google Play Store metrics, featuring automated data cleaning, missing value imputation, log transformations, recency feature engineering, and app performance insights.

## Project Structure
- `App_Trend_Analysis (2).ipynb`: Main Jupyter notebook containing data preprocessing, exploratory data analysis (EDA), and feature engineering.

   git clone https://github.com/Nandu82005/app-trend-analysis.git
